# pachagames.com

Static site served by GitHub Pages, plain HTML with no build step.

- `index.html`: studio home page
- `jellydash/`: Jelly Dash page
- `cardlink/`: redirect used by the business card QR code; point it at the Steam page once that is public
- `riftjumpers/`: Rift Jumpers press kit
- `riftjumpers/play/`: playtest page, using the official itch embed
- `riftjumpers/pitch/`: trailer and the one-pager (fixed 794x1123 markup, scaled to fit) for publishers, not linked from other pages
